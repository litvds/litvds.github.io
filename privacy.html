Privacy Policy

Ember & Rain Studio · Last updated: November 3, 2026

Ember & Rain Studio is a private application operated by the owner of the Ember & Rain YouTube channel and used solely to manage that channel.

Data we access

With the owner's authorization through Google OAuth, the application uses the YouTube Data API, YouTube Analytics API and YouTube Reporting API to access the owner's own channel: video and playlist metadata, uploads, and channel analytics.

How data is used

The data is used only to upload and edit the channel's own videos and playlists and to produce analytics for the channel owner. It is not sold, shared with third parties, or used for advertising.

Storage and security

OAuth tokens and analytics are stored on a private server controlled by the channel owner and are not publicly accessible. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. See also the Google Privacy Policy.
